## 📁 Estrutura do Projeto
- **`index.html` / `app.js`**: Versão web HTML5 pura com Tailwind CDN, tipografia Google Fonts, máscara de telefone, menu mobile e disparo de mensagens estruturadas para o WhatsApp.
- **`frontend/`**: Aplicação React 19 + Vite com Hot Module Replacement (HMR).
- **`backend/`**: Servidor API REST Node.js/Express e banco de dados SQLite.
